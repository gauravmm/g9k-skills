# Send documents to Viwoods AiPaper

- For a document outside the COS workspace that Gaurav asks to receive, submit the original Markdown or PDF through [COS Intake](http://cherusci.tail1d9089.ts.net:8766/instructions). Follow the file and receipt instructions.
- A delivered intake receipt confirms Telegram delivery. To get a tablet copy, Gaurav asks COS in Telegram to send the attachment to his reader.
- If you are COS and Gaurav requests a tablet copy, use `epaper_document_send` with the retained media ID or a workspace-relative path. COS renders Markdown at tablet size and sends PDFs as supplied.
- Report when Viwoods Learning accepts the file. Gaurav verifies tablet sync and offline availability.
